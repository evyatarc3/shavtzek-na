# שבצ״ק נא

לו״ז, נוכחות ושבצ״ק למפקדים: סבבי בית ותעסוקה, יציאות ואילוצים, חוקת משימות, שבצ״ק ושמירות אוטומטיים, צל״ם ופק״לים, ותיבת "שאל" לשאלות חופשיות.

**הקישור לאפליקציה:** https://evyatarc3.github.io/shabtzak-na/

## פרטיות

- **הכול נשמר רק בטלפון.** לאפליקציה אין שרת, אין הרשמה ואין מעקב.
- **חסימה טכנית.** האפליקציה חסומה מלהתחבר לכל כתובת חיצונית (Content-Security-Policy). גם הגופנים וספריית האקסל יושבים בתוכה.
- **בלי חיבור.** אחרי הפתיחה הראשונה היא עובדת גם בלי קליטה.
- **המאגר הזה ציבורי, אבל אין בו אף נתון של יחידה.** הנתונים בבדיקות (`tests/fixture.json`) מומצאים.
- **גיבוי.** הנתונים יושבים רק בטלפון, ולכן כדאי לשמור גיבוי לקובץ מדי פעם: עוד ← מבנה, סבבים וגיבוי. האפליקציה מזכירה כל שלושה ימים.

## התקנה בטלפון

**iPhone**
1. פותחים את הקישור ב-**Safari**. אם הוא נפתח בתוך וואטסאפ, בוחרים "פתיחה ב-Safari".
2. לוחצים על כפתור השיתוף ← **הוספה למסך הבית**.
3. מעכשיו פותחים רק מהאייקון. ב-iPhone האפליקציה שבמסך הבית שומרת את הנתונים בנפרד מ-Safari.

**אנדרואיד**
1. פותחים את הקישור ב-**Chrome** ← ⋮ ← **התקנת אפליקציה**.
2. אחרי ההתקנה אפשר לשתף עדכון מוואטסאפ ישר לאפליקציה: לחיצה ארוכה על ההודעה ← שיתוף ← שבצ״ק נא.

## שיתוף בין מפקדים (מוצפן, בלי שרת)

עוד ← **שיתוף מוצפן עם מפקדים**.

1. כל המפקדים במסגרת קובעים **סיסמת יחידה** אחת. מעבירים אותה פעם אחת, בעל פה או בהודעה נפרדת.
2. **שליחה:** "שליחה כהודעה" או "שליחה כקובץ". נשלח הקו כולו, מוצפן בטלפון (AES-256). בצ׳אט ובגיבויים של וואטסאפ רואים רק רצף תווים.
3. **קבלה:** מדביקים את ההודעה, או בוחרים את הקובץ, ואז "פתיחת העדכון". לפני המיזוג מוצג מה ישתנה. מכל רשומה נשמר השינוי החדש יותר, ומחיקות עוברות גם הן.
4. **טלפון חדש:** במסך הראשון יש "קיבלתם עדכון ממפקד?", והקו כולו נטען משם.

## חוקת משימות

עוד ← **חוקת משימות**:
- **כללי:** מנוחה מינימלית, מנוחה אחרי לילה, ומקסימום משמרות ביום, בשבוע ולילות בשבוע.
- **לכל משימה:** מי רשאי (כולם / מוסמכים לפי פק״ל / מפקדים / רשימה), מה חובה בכל משמרת, פטורים, ו**תור קבוע** שממשיך מאיפה שעצר.
- **פטורים אישיים:** מלילות, ממשימה או מהכול, עם תאריך סיום.

השבצ״ק נבנה לפי החוקה. כשמשבצת נשארת ריקה, כתוב למה, למשל "חסרים 2 · 6 במנוחה, 3 הגיעו לתקרה". בשיבוץ ידני מופיע ליד כל חייל אם הוא בפטור, בלי הסמכה או מעל התקרה.

## מעבר מהדף ב-Claude

בדף הישן: עוד ← מבנה, סבבים וגיבוי ← **שמירת גיבוי לקובץ**. באפליקציה החדשה, במסך הראשון: **יש לי גיבוי: שחזור מקובץ**.

## למפתחים

אפליקציית רשת סטטית, בלי שלב בנייה. `index.html` טוען את הקבצים שב-`js/` לפי הסדר. ההסבר המלא נמצא ב-[`CLAUDE.md`](CLAUDE.md).

```
npm install           # Playwright, רק לבדיקות
npm run serve         # http://localhost:8770
npm run test:engine   # מנוע: חוקה, מיזוג, הצפנה
npm run test:e2e      # שני טלפונים, עבודה בלי רשת, בלי בקשות החוצה
npm run stamp         # אחרי כל שינוי בקבצים: מעדכן את sw.js
```

כל דחיפה ל-`main` מריצה את הבדיקות ומפרסמת את האתר. ההגדרה החד-פעמית: Settings ← Pages ← Source: **GitHub Actions**.
