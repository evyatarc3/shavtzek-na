# שבצ״ק נא — notes for Claude Code

A duty-roster web app for IDF reserve commanders (Hebrew, RTL, phone-first). Static files only,
served from GitHub Pages, installed to the home screen as a PWA. **No server, ever.**

## Hard rules

- **Data never leaves the device.** No fetch/XHR/WebSocket to anything but the app's own files.
  `index.html` has a strict Content-Security-Policy (`connect-src 'self'`, no remote scripts, fonts or
  styles). Keep it that way: vendor any library into `vendor/`, fonts into `fonts/`.
- **Never commit real unit data** (names, soldiers, equipment serial numbers, dates of a real line).
  Tests use `tests/fixture.json`, which is invented. `.gitignore` blocks backup/update file names.
- Sharing between commanders is only the encrypted update in `js/15-share.js` (copy/paste or a file).
- UI copy is Hebrew, short, phone-friendly, gender-neutral where easy. Numbers that can be negative
  are bidi-isolated (see the `.num`/`direction:ltr` rules in `css/app.css`).

map in `06-day.js` (and a row in `vMore`).

## Data model (localStorage key `shabtzak-app-v1`)

`{ config, soldiers, tasks, rules, rosters, tomb }`. Every record written through `put(path, obj)`
gets `_t` (ms); `put(path, null)` leaves `tomb[path] = time`. Paths: `line/config`, `soldiers/<id>`,
`tasks/<id>`, `rules/<id>`, `rosters/<YYYY-MM-DD>`. `config.lineId` identifies a line across phones.

Rulebook fields:
- `settings`: `minRest`, `restAfterNight`, `maxPerDay`, `maxPerWeek`, `maxNightsWeek`, `nightFrom`, `nightTo`.
- task: `who: {mode:"all"|"tags"|"cmd"|"list", tags, list}`, `exempt: [pid]`, `queue: {on, order:[pid]}`,
  `cmd`, `needs: [{tag,count}]`, `rest`, plus shape fields (`size`, `len`, `hours`, `start`, `days`, `platoons`).
- person: `exempt: [{scope:"all"|"night"|"task", task?, until?, reason?}]`.

Engine entry points: `ruleReasons()` (static eligibility), `restAfter()`, caps and queue order inside
`fillSlot()`; `slotConflicts()` mirrors them for manual assignment.

## Encrypted update format

`SHBZ1.` + base64url(`[1, zipped]` + salt16 + iv12 + AES-GCM ciphertext). Key: PBKDF2-SHA256,
250,000 iterations, from the unit password after `passNorm()` (NFC, trim; a digits-only password drops spaces
and dashes, so the generated `1234-5678-…` codes can be typed either way). Payload: `{app:"shabtzak", kind:"update", v:2, from, at,
line, lineName, config, soldiers, tasks, rules, rosters, tomb}`; deflate-raw before encryption.
Merge: newer `_t` wins per record; tombstones delete and block stale copies; a different `line` → replace.

## Working on it

- `npm run serve`, open http://localhost:8770.
- After changing any app file: `npm run stamp` (CI fails if `sw.js` is stale).
- Tests: `npm run test:engine` (Node only) and `npm run test:e2e` (Playwright; `npx playwright install chromium`
  first, or set `PW_CHROMIUM` to a Chromium binary). Screenshots land in `tests/shots/` (ignored).
- Push to `main` → GitHub Actions runs the engine tests and publishes to Pages.
